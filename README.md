# Focus Cat

Focus Cat is a small desktop application to use while working or studying. When started a small pixelated cat pops up, sitting on a timer. 

When the timer is started, the cat sleeps and lets you work in silence. When the time is over, it wakes up making the user take a small break, like drink some water. When the pause is over, it can make the cat go to sleep again.

The timer and pause durations and UI colors can all be customized in the settings.
